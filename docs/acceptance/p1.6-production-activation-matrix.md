### 3.3 Mutations **CHỈ ĐƯỢC** chạy ở Phase C

Để giảm blast radius, các mutation sau **không** chạy ở Phase B:

- R2 PUT/Finalize thật (`reserveDirectEntryDocument`, `finalizeDirectEntryDocument`) — vì R2 Production env đã wire-in (Owner-attested), Phase B **không** test `DOCUMENT_STORAGE_UNAVAILABLE`. Document/R2 lifecycle để Phase C controlled acceptance với manifest + cleanup.
- `downloadDirectEntryDocument` — chỉ test ở Phase C khi đã có finalized document.
- Submission transition `REVIEW→SUBMITTED` (chỉ chạy khi đã có batch tạo từ Phase C + UI).

Phase B chỉ smoke:
- Auth/session/catalog/read boundaries;
- Synthetic mutation trên submission DRAFT (transition DRAFT↔REVIEW, batch create với synthetic employee_code);
- Capability/redaction/actor-field/OCC/idempotency;
- Không ghi R2 object nào ở Phase B.

Document/R2 lifecycle smoke để Phase C controlled acceptance.
