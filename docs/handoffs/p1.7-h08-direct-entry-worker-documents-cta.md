# P1.7-H08 — Fix "Hồ sơ NLĐ" không bấm được trên Production

## Bối cảnh

Sau khi I05 đẩy H07 lên Production, Owner phát hiện:

- Click chọn một dòng đã lưu (persisted) → nút `Hồ sơ NLĐ` xuất hiện trong contextual action bar nhưng **không bấm được**, UI không giải thích lý do trực tiếp (chỉ có `title` tooltip khi hover, không có copy inline).
- Staged row → nút `Hồ sơ NLĐ` cũng hiển thị (disabled) → Owner tưởng có thể bấm để upload, thực tế phải save trước.
- Sau khi save staged row thành công → selection không tự chuyển sang persisted row, hoặc chuyển nhưng nút vẫn disabled.
- Một số user có `entry_admin` (không phải `entry_own`) + `document_view` + `document_upload` → nút disabled vì predicate cũ chỉ nhận `entry_own`.

## Truy nguyên trạng thái disabled (file: `direct-entry-live.tsx` ~line 1755-1777, sau H07)

```ts
disabled={selected === null
  || selectedIsStaged
  || !selectedHasEntryId
  || (!canEditDocs && !canOpenReadOnly)}
```

Với:
```ts
const canViewDocs = capabilities.includes("document_view");
const canEditDocs = selectedHasEntryId
  && capabilities.includes("entry_own")
  && capabilities.includes("document_upload");
const canOpenReadOnly = selectedHasEntryId && canViewDocs && !canEditDocs;
```

### Nguyên nhân gốc

1. **Predicate cũ yêu cầu `entry_own` cho edit path** — không nhận `entry_admin`. Owner với `entry_admin + document_view + document_upload` rơi vào `canEditDocs = false`, `canOpenReadOnly = true` → enabled (vẫn OK), nhưng **nếu user thiếu `document_view`** → cả hai false → disabled với title "Bạn không có quyền xem hồ sơ". Đây là nhánh "không giải thích lý do" khi user có `entry_admin` thuần (không `document_view`) — production không lường được case này.

2. **`title` attribute chỉ hiện khi hover** — touch device / mobile không có hover. Inline explanation phải có.

3. **Staged row hiển thị nút disabled** "Hồ sơ NLĐ" mà không copy inline → user tưởng click được. Phải thay bằng text "Lưu NLĐ để thêm hồ sơ".

4. **`selectedHasEntryId` dùng `rows.some(...)`** làm proxy cho việc check entry_id từ server. Logic dư thừa (vì `selected.persisted === (row.entryId !== null)`), nhưng nếu giữa lúc user chọn row và lúc server vừa cấp entry_id cho row mới save (`setSelectionAfterSaveEntryId` chưa resolve xong), `rows` chưa có row với `entry_id` mới → `selectedHasEntryId = false` → button disabled với title không khớp.

5. **Stale `selectedClientRowId`**: Khi row bị xóa/reload, `selectedSpreadsheetRow` trả về `null` nhưng state vẫn giữ id cũ. UI hiển thị "Chọn một dòng để thao tác" nhưng `selected !== null` trong render → guard `selected === null` không catch được.

## Fix

### 1. Capability gate mới

```ts
const canViewDocs = capabilities.includes("document_view");
const canEditDocsOnSelected = canViewDocs
  && selectedHasEntryId
  && (capabilities.includes("entry_own") || capabilities.includes("entry_admin"))
  && capabilities.includes("document_upload")
  && isRowEditable(selected, submissions);
const canOpenWorkerDocuments = canViewDocs && selectedHasEntryId;
const missingCapabilityReason = !canViewDocs
  ? "Bạn không có quyền xem hồ sơ"
  : null;
```

- `canOpenWorkerDocuments` chỉ yêu cầu `document_view` + row có `entry_id`. Mở dialog là xem được, không cần `entry_own`/`document_upload`.
- `canEditDocsOnSelected` cho phép `entry_own` hoặc `entry_admin` + `document_upload` + `isRowEditable`. Prop `canEditDocuments` của `DirectEntryWorkerDocuments` đã gate đúng.
- Thông báo "Bạn không có quyền xem hồ sơ" hiển thị inline trong bar (không phải nút chết).

### 2. Staged row → text inline, không nút dead

```ts
if (selectedIsStaged) {
  // Khong render button Hồ sơ NLĐ; chi render text.
  return <p className={styles.contextualActionHint} data-testid="contextual-staged-hint">
    Lưu NLĐ để thêm hồ sơ.
  </p>;
}
```

`Lưu NLĐ` clickable, mở quick editor để user sửa/save.

### 3. Post-save selection resolution

Đã có sẵn `selectionAfterSaveEntryId` + render-time resolve (H06). Cần:
- Sau khi `reloadDrafts()` chạy xong, nếu `rows` có row với `entry_id` trùng → set selection sang row đó.
- Hiện tại logic đã đúng (xem line ~1185-1205). Test H06-17 đã cover.

### 4. Stale selection cleanup

Thêm effect clear `selectedClientRowId` khi không còn row nào trong `spreadsheetRows` khớp:

```ts
useEffect(() => {
  if (selectedClientRowId === null) return;
  const stillExists = spreadsheetRows.some((row) =>
    row.clientRowId === selectedClientRowId);
  if (!stillExists) setSelectedClientRowId(null);
}, [spreadsheetRows, selectedClientRowId]);
```

Đặt **sau** `selectionAfterSaveEntryId` resolution render-time block (line ~1185) để không clear ngay sau khi save.

### 5. Bảo vệ click handler khi thiếu quyền

`onClick` của nút `Hồ sơ NLĐ` cũ guard `selected === null` và `!selectedHasEntryId`. Bổ sung thêm `!canViewDocs` để defense-in-depth (khi disabled do CSS/overlay issue vẫn không mở dialog).

### 6. CSS — không pointer-events chặn

CSS `.contextualActionButton:disabled` chỉ đổi `cursor` + `opacity`. Không có `pointer-events: none`. Kiểm tra xong — không có overlay nào khác.

## Out of scope (đã tránh)

- Không sửa `DirectEntryWorkerDocuments` (gate `canEdit` / `canView` đã đúng, dialog `open` đúng).
- Không sửa server authority, không sửa capability list.
- Không migration, không DB apply, không R2 thật.
- Không tạo dialog/upload flow mới.
- Không thay đổi 18 grid columns, XLSX, Ctrl+V, Người tuyển/Vendor behavior.

## Tests bổ sung (`direct-entry-h08-worker-documents-cta.test.mjs`)

1. Persisted + `document_view` → nút enabled và `setDocumentsRowId(persisted.rowId)`.
2. Persisted + view-only (chỉ `document_view`) → nút enabled (mở dialog), prop `canEditDocuments = false`.
3. Persisted + `document_view + document_upload + entry_own` → nút enabled, `canEditDocuments = true`.
4. Persisted + `document_view + document_upload + entry_admin` (không `entry_own`) → nút enabled, `canEditDocuments = true` (gate mới nhận `entry_admin`).
5. Persisted + thiếu `document_view` → hiện inline "Bạn không có quyền xem hồ sơ", **không** có nút dead.
6. Staged row → hiện "Lưu NLĐ để thêm hồ sơ", **không** có nút Hồ sơ NLĐ.
7. `selectionAfterSaveEntryId` resolve sang persisted row sau reload → nút Hồ sơ NLĐ enabled.
8. Stale `selectedClientRowId` (row bị xóa) → effect clear, bar hiện "Chọn một dòng để thao tác".
9. Click handler guard `!canViewDocs` không mở dialog.
10. Không regression H06 / H07.
