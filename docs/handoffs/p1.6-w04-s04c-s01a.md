## 1. Transition matrix

| Từ | Đến | Nguồn quyết định | Kết quả đã kiểm |
| --- | --- | --- | --- |
| DRAFT | REVIEW | application cho qua, RPC + trigger DB | 200, version +1 |
| REVIEW | DRAFT | application cho qua, RPC + trigger DB | 200, version +1 |
| REVIEW | SUBMITTED | application cho qua, RPC + trigger DB | 200, version +1, submitted_at duoc ghi |
| DRAFT | SUBMITTED | **DB trigger tu choi** (SQLSTATE 40001) | 409, state giu nguyen DRAFT |
| SUBMITTED | DRAFT/REVIEW | **DB trigger tu choi** (terminal) | 409 |
| X | X (no-op) | RPC guard tu choi (SQLSTATE 22023) | 400 |

Ma tran khai bao o `SUBMISSION_TRANSITIONS` (contract) va duoc kiem bang `isAllowedTransition`; DB van la noi enforce cuoi cung qua trigger `direct_entry_submission_transition` (before update) va `direct_entry_submission_transition_guard`.

Application **khong** tu quyet dinh DRAFT -> SUBMITTED la hop le hay khong: route khong doc trang thai hien tai (khong tao TOCTOU, khong tao authority thu hai), nen moi duong tat deu bi DB chan va duoc giu nguyen ma loi (40001 -> 409).

## 2. Boundary actor / capability / OCC / idempotency

| Hạng mục | Quyết định ở đâu | Ghi chú |
| --- | --- | --- |
| Session | `auth.getUser()` qua `resolveDirectEntrySession` (khong dung getSession) | Route goi `getDirectEntryActor(createDirectEntryActorRepository())` nhu cac route mutation hien co |
| Actor | server-derived `auth_subject` + `app_user_id` | Client khong bao gio gui actor; contract tu choi moi truong authority |
| Capability (`submission_create`) | RPC `direct_entry_assert_actor` | Application khong danh gia capability |
| Scope (own scope grant + created_by) | RPC | 42501 -> 403 |
| OCC | RPC (`p_expected_version` so voi `submission.version`) | 40001 -> 409 |
| Idempotency | helper `direct_entry_idempotency_*` trong RPC | Cung key + cung payload -> replay cung outcome; cung key + payload khac -> 22023 reuse -> 409 |

Idempotency key nam trong body (truong `idempotency_key`, 1..128 ky tu, khong ky tu dieu khien). Neu client cung gui header `idempotency-key` thi gia tri **phai khop** body, neu khong tra 400 `IDEMPOTENCY_KEY_MISMATCH` — tranh hai nguon su that.

## 3. Request projection (fail-closed)

`projectSubmissionTransitionRequest` chi nhan dung ba truong:

| Truong | Kieu | Rang buoc |
| --- | --- | --- |
| expected_version | integer | >= 1, safe integer |
| target_state | enum | REVIEW hoac DRAFT hoac SUBMITTED |
| idempotency_key | string | 1..128, khong rong sau trim, khong ky tu dieu khien |

Tu choi:

- truong la hoac thieu truong -> 400 `SUBMISSION_TRANSITION_INVALID`;
- truong authority/derived (ke ca long ben trong object/array) -> 400 `CLIENT_AUTHORITY_FIELD_FORBIDDEN`: actor_id, app_user_id, auth_subject, actor, role(s), capability/capabilities, scope(s), scope_kind, team_id, provider_type, created_by_user_id, owner_user_id, user_id, session_id, state, version, submission_version, submitted_at, created_at, updated_at, audit/audit_event_id, revision/revision_id/revision_number, tenant.

## 4. Response projection (exact, fail-closed)

RPC `direct_entry_transition_submission` tra ve dung ba truong, nen response cung dung ba truong:

| Truong | Ghi chu |
| --- | --- |
| submission_id | uuid, phai khop submission trong URL |
| state | DRAFT hoac REVIEW hoac SUBMITTED |
| version | phai bang `expected_version + 1` |

Quyet dinh co chu dich: **khong** tra `submitted_at`, `reused`, `revision_id` hay audit metadata vi RPC khong tra cac truong do — them vao se la bia du lieu. `submitted_at` do DB trigger ghi va co the doc qua projection cua entry khi UI can.

Bat ky payload nao lech (thua/thieu truong, sai state, version khac `expected_version + 1`, submission_id khac) bi project thanh `unavailable` -> 500 sanitized; **khong** dung type assertion de tin raw RPC JSON.

## 5. Error mapping

| Tinh huong | HTTP | Code |
| --- | --- | --- |
| Gate `DIRECT_ENTRY_API_ENABLED` != true | 404 | NOT_FOUND |
| Sai origin/CSRF | 403 | CSRF_REJECTED |
| submissionId khong phai uuid | 400 | SUBMISSION_ID_INVALID |
| Content-type khong phai JSON / body khong doc duoc | 400 | CONTENT_TYPE_INVALID / BODY_INVALID |
| Request sai hoac chua truong authority | 400 | SUBMISSION_TRANSITION_INVALID / CLIENT_AUTHORITY_FIELD_FORBIDDEN |
| Header idempotency-key khac body | 400 | IDEMPOTENCY_KEY_MISMATCH |
| Chua dang nhap | 401 | UNAUTHENTICATED |
| Actor thieu/khong map/disabled/ambiguous hoac actor malformed | 403 | ACTOR_NOT_AVAILABLE |
| Capability/scope/khong phai chu submission | 403 | SUBMISSION_DENIED |
| Khong tim thay submission | 404 | SUBMISSION_NOT_FOUND |
| OCC stale, SUBMITTED terminal, DRAFT -> SUBMITTED, idempotency payload conflict | 409 | SUBMISSION_CONFLICT |
| No-op transition, batch rong | 400 | SUBMISSION_TRANSITION_INVALID |
| RPC/DB loi khac hoac projection malformed | 500 | SUBMISSION_UNAVAILABLE |

Khong tra raw DB message, stack, auth claim hay chi tiet SQL; log chi la cau thong bao tinh, khong chua id/PII.
