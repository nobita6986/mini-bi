## Scope and release status

Release source: `524961e6b515774b88df3cf68f49b46c5437b384`, fast-forwarded to `origin/main`
from `81191c8b87daee3e86a02cce6f7c777ef15374fa`.

The release is deployed to Production and migration #39 is applied. The unauthenticated
Production smoke of `/dashboard` was investigated after the initial status-code-only concern.
The route uses a Next.js streaming Server Component redirect: the credential-free HTML response
is HTTP 200, has no `Location` or `x-nextjs-redirect` header, and contains a meta refresh to
`/login?next=/dashboard`. The response included the dashboard shell/heading but no checked
report KPI, chart, or serialized reporting-data markers. In source, the session access decision
and redirect execute before either reporting fetch. This is consistent with streaming redirect
semantics, not evidence of a reporting-data disclosure; no production hotfix was made.

An unauthenticated RSC smoke was also attempted. A bare `RSC: 1` request returned
`text/x-component` without checked reporting-data markers, but did not carry a verifiable
navigation redirect. A second request with a synthesized router-state header returned a generic
platform HTTP 500. Since that synthetic request did not produce a valid Flight navigation, its
result is inconclusive and is not used to claim RSC auth acceptance. Owner final UI UAT remains
pending; do not claim P1.7 PASS or Production-ready.
