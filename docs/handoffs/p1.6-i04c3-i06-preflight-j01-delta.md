## 3. Locked product policy

- `account_number`, `bank_name` and `account_holder_name` are optional profile
  text fields, comparable to address or gender for this product. They do not
  execute payments.
- A zero-row bank catalog is valid and must not block non-payment or
  full-profile import.
- Migration #38 and the account-metadata edit branch are excluded. I06 must not
  integrate, apply or depend on them.
- The legacy payment editor and bank autocomplete are not P1.6 activation
  dependencies. A future generic worker-profile editor may handle post-create
  edits.
- `Mã NLĐ` is the canonical display header. `Mã số ứng viên` and `Mã nhân viên`
  remain import aliases only.
- CCCD objects use opaque storage keys. Names, employee codes and national IDs
  must not appear in object keys, filenames, logs or screenshots.
- The Preview and Production buckets remain separate:
  `hrp-bi-preview` and `hrp-bi-product`.

## 6. Activation authority and stop rules

I05A PASS is recorded at integration commit `2970d73`. I06 may start through
the controlled matrix. At execution time, stop before mutation if any of these
drift:

- Production alias, deployment source SHA or target;
- migration state other than 37/0/0;
- migration #38 present in source or database;
- API or required R2/Supabase/Pilot keys missing;
- I05A authenticated session, actor or read-only API failure;
- Preview and Production bucket separation cannot be proven.

After activation, any authentication regression, authorization leak, catalog
resolution error, non-atomic batch result, raw PII/storage metadata exposure,
wrong-bucket operation, unexplained reporting drift or unbounded cleanup is an
immediate stop-and-rollback condition.
