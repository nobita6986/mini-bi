## 5. Semantics partial/running/stale
- `everSucceeded` = `last_successful_sync_at != null`; `hasCurrentFacts` = có ≥1 fact snapshot hiện hành (độc lập filter); `contributes` = có facts cộng vào result.
- Status: succeeded→covered, partial→incomplete, failed+facts→stale_snapshot, failed+no facts→never_succeeded, running→running, chưa run→no_run.
- `coverageRatio` dựa `everSucceeded`; source filter thu hẹp coverage/status về source được chọn.
- `dateExtent` = extent của result sau filter (min/max `business_date` facts đã lọc).
- Partial lần đầu: facts tính, `contributes=true`, `everSucceeded=false`, `status=incomplete`, `coverageRatio` chưa tính nó là từng succeeded.
