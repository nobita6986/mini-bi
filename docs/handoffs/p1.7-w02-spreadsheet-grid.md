### 3.1 Validation adapter — single source of truth

The adapter does not restate a single business rule. It:

1. serializes the non-blank staged rows to TSV using the canonical headers of the registry's
   write columns, in physical order;
2. calls the existing `buildWorkerProfilePreview` with the existing
   `createPasteCatalogResolver`;
3. maps each issue back to `clientRowId` + column key, translating messages through the
   existing `workerProfileIssueMessage`.

Consequences: no duplicated regex, no duplicated catalog resolution, no duplicated date/gender/
labour-type/status vocabulary, and blank rows are never validated.

### 3.2 Component exports

```ts
export const SPREADSHEET_GRID_ARIA_LABEL = "Bảng nhập liệu Direct Entry";
export type SpreadsheetGridRow = { clientRowId, persisted, locked, cells, editableFields,
  employeeCode, displayName, projectLabel, recruiterLabel, saveStatus };

export type DirectEntrySpreadsheetGridProps = { rows, validation, catalogOptions,
  onCellsChange, onPasteApplied, onPasteRejected, onClearRow, onDeleteRow, onDuplicateRow,
  onManageDocuments?, onSave, saveLabel, saveDisabled, saveBusy?, notice, canUndo, onUndo,
  saveMessage? };
export function DirectEntrySpreadsheetGrid(props): JSX.Element;
export function spreadsheetSelectOptions(columnKey, catalogs): readonly string[] | null;
```

The component renders all 27 registry columns from `DIRECT_ENTRY_GRID_COLUMNS` (no hard-coded
column list), is fully controlled, and owns no row state.

### 3.3 Paste path

The pinned grid exposes native `onCellPaste`/`onCellCopy`/`onCellKeyDown` with the active
cell, so the anchor is taken from the real event target rather than from a separate selection
tracker. Paste reads `event.clipboardData.getData("text/plain")` inside a user-initiated
handler, calls the W01 pure parser and mapper, and reports the result upward.

The component contains **no** `fetch`, **no** `localStorage`/`sessionStorage`, **no**
`navigator.clipboard`, and **no** background clipboard read. Overflow is rejected before any
cell is applied, so a rejected paste cannot partially mutate state.
