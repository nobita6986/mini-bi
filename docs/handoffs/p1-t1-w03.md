## 2. Fail-closed
- development: bỏ qua gate (pnpm dev).
- production/preview thiếu `PILOT_ACCESS_USERNAME`/`PILOT_ACCESS_PASSWORD` ⇒ 503 (body cố định `Pilot access unavailable`).
- thiếu Authorization / sai scheme / base64 lỗi / thiếu `:` / sai credential ⇒ 401.
- 401 có `WWW-Authenticate: Basic realm="Mini BI Pilot", charset="UTF-8"`.
- 401/503 có `Cache-Control: private, no-store` + `Vary: Authorization`.
