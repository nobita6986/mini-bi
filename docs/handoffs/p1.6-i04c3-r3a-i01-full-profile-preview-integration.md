Full-profile **chưa** được nối vào server. Còn chờ T1B:

1. Migration mở rộng `direct_entries`: `gender`, `national_id_issued_at`, `national_id_issued_place`,
   cột top-level `general_note`, cùng validator `direct_entry_valid_worker_details` tương ứng.

   status event lịch sử).
3. Contract `worker-profile/1.0` phía server khớp vocabulary/alias và mã lỗi của client.
4. Response có `entry_ids` theo đúng thứ tự input + `rows[]` + `warnings[]`.
5. Nâng `MAX_BODY_BYTES` cho batch hồ sơ đầy đủ (khuyến nghị ≥ 128 KiB).
6. Danh mục ngân hàng có dữ liệu và `direct_entry_input_catalog` trả `banks` (và `teams[]`).
