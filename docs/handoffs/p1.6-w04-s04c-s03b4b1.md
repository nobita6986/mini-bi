# P1.6-W04-S04C-S03B4B1 — DOCUMENT change-request scope lock

## Decision and boundary

T0 selected option 1: **P1.6 does not support DOCUMENT through change requests.**
Create requests accept only `ENTRY_FIELD`, `PAYMENT`, and `WORK_STATUS`.
The application contract rejects a DOCUMENT item (including any mixed request)
with a sanitized HTTP 400 before session resolution or repository/RPC dispatch.
The historical DOCUMENT vocabulary and read projection remain available for
compatibility; they do not make DOCUMENT mutable.

The product path for a document remains the existing direct R2 upload flow:
`document_upload` capability, optimistic concurrency, revision and audit
recording, and a reason when the hồ sơ is already `SUBMITTED`. This scope lock
does not alter the direct R2 reserve/finalize/download RPCs or the upload
contract.

This is pre-go-live hardening, not an incident. The pre-apply read-only DEV
query found **0** DOCUMENT change-request items; no historical row, audit, or
revision was deleted or modified.
