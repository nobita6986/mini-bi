## 4. Projection schema (strict, fail-closed)

**List item** — đúng 8 key: `submission_id` (uuid), `state` (DRAFT|REVIEW|SUBMITTED), `version` (int ≥ 1), `entry_count` (int 0..500), `created_at`, `updated_at` (ISO UTC `YYYY-MM-DDTHH:MM:SS.uuuuuuZ`), `submitted_at` (null hoặc ISO UTC), `allowed_transitions`.

**Detail** — thêm `entry_ids` (uuid[], sắp xếp tăng dần theo uuid = deterministic, không trùng, độ dài = `entry_count`).

Bất biến bị từ chối:

- `submitted_at` khác null khi state DRAFT/REVIEW;
- `SUBMITTED` mà `submitted_at` null hoặc sai định dạng;
- `allowed_transitions` không khớp đúng ma trận của state (DRAFT → [REVIEW]; REVIEW → [DRAFT, SUBMITTED]; SUBMITTED → []), kể cả sai thứ tự hoặc thừa/thiếu phần tử;
- timestamp không phải ISO UTC 6 chữ số micro;
- version/entry_count không phải integer hợp lệ (`0`, `1.5`, chuỗi, boolean đều bị loại);
- key thừa/thiếu, `entry_ids` trùng, không phải uuid, hoặc lệch `entry_count`;
- `next_cursor` sai kiểu hoặc khác null khi `has_more = false`;
- fallback `[]`, `0`, `false` cho dữ liệu thiếu.

`allowed_transitions` là **display hint server-derived**; mutation RPC vẫn là authority cuối và UI không được coi array này là authorization proof (đã ghi rõ trong comment contract).

**Không trả**: created_by_user_id, auth subject/app user, capability/scope grants, worker details/PII, payment/document, audit/revision/reason, idempotency key/hash, timestamp/DB field ngoài contract.

## 5. Pagination / cursor

- `page_size` 1..50, mặc định 20; text phải khớp `^[1-9][0-9]{0,2}$` (từ chối `0`, `020`, `1.5`, rỗng).
- Thứ tự cố định `created_at DESC, submission_id DESC` (tổng, không trùng).
- Cursor opaque do DB sinh `<yyyyMMddHH24MISSUS UTC>:<submission_id>`; so sánh tuple text nên hai submission cùng `created_at` vẫn tách đúng, không trùng/không sót.
- `next_cursor = null` khi `has_more = false`.
- Chỉ nhận 3 tham số `page_size | cursor | state`; tham số khác (`order`, `column`, `offset`, `limit`, `sql`…) bị từ chối 400 — client không điều khiển sort/column/SQL.

## 6. HTTP semantics

| Tình huống | HTTP | Code |
| --- | --- | --- |
| Gate tắt | 404 | NOT_FOUND |
| Query/path sai (page_size, cursor, state, tham số lạ, uuid sai) | 400 | SUBMISSION_QUERY_INVALID / SUBMISSION_ID_INVALID |
| Chưa đăng nhập | 401 | UNAUTHENTICATED |
| Actor thiếu/malformed/disabled | 403 | ACTOR_NOT_AVAILABLE |
| Mapping/capability/own scope denied ở RPC | 403 | SUBMISSION_READ_DENIED |
| Không tồn tại **hoặc** của actor khác | 404 | SUBMISSION_NOT_FOUND (cùng một mã) |
| RPC lỗi khác / projection malformed / throw | 500 | SUBMISSION_UNAVAILABLE |

Mọi response thành công có `Cache-Control: private, no-store`; không log identity/cursor/raw DB error; không dùng `getSession()` (đi qua `getDirectEntryActor` → `auth.getUser()`).
