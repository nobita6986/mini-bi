## 1. RPC thực tế (đọc từ migration 20261002170000, không đoán)

| RPC | Signature | Result jsonb | Ghi chú |
| --- | --- | --- | --- |
| direct_entry_create_change_request | (p_auth_subject uuid, p_app_user_id uuid, p_items jsonb, p_reason text, p_idempotency_key text) | { request_id, state: "PENDING", items: <số item> } | items 1..100; mỗi item đúng 4 key |
| direct_entry_withdraw_change_request | (p_auth_subject uuid, p_app_user_id uuid, p_request_id uuid, p_expected_version integer, p_idempotency_key text) | { request_id, state: "WITHDRAWN", version } | version = expected + 1 |
| direct_entry_approve_change_request | (p_auth_subject uuid, p_app_user_id uuid, p_request_id uuid, p_expected_version integer, p_reason text, p_idempotency_key text) | { request_id, state: "APPROVED", version } | wrapper mỏng gọi helper với decision APPROVED |
| direct_entry_reject_change_request | (p_auth_subject uuid, p_app_user_id uuid, p_request_id uuid, p_expected_version integer, p_reason text, p_idempotency_key text) | { request_id, state: "REJECTED", version } | wrapper mỏng gọi helper với decision REJECTED |
| direct_entry_decide_change_request (helper) | (…, p_decision text, …) | như trên | **KHÔNG được grant cho service_role**; application không gọi trực tiếp (DEV acceptance kiểm bằng has_function_privilege) |

Vocabulary item/proposal (đúng theo RPC, không mở rộng):

| target_kind | proposal keys |
| --- | --- |
| ENTRY_FIELD | project_id, first_work_date, employee_code, worker_details, recruiter_id, labor_type (không được rỗng) |
| PAYMENT | state, account_number, bank_id, account_holder_name (đúng 4 key, dùng lại projectPaymentInput) |
| WORK_STATUS | status, effective_date, leave_reason (OFF bắt buộc leave_reason; ON/UNCONFIRMED phải null/không có) |
| DOCUMENT | document_type, idempotency_key, checksum_sha256, size_bytes, mime_type (đủ 5 key) |

Timestamp/reviewer identity/revision id/reused/affected rows **không** có trong result RPC nên projection cũng không bịa ra.

## 2. Ma trận hành động

| Hành động | Điều kiện DB enforce | Kết quả |
| --- | --- | --- |
| create | capability change_request_create + scope từng entry + mọi entry thuộc submission SUBMITTED + expected_version khớp | PENDING (version 1) + request revision + audit + idempotency |
| withdraw | proposer + request PENDING + expected_version khớp | WITHDRAWN (version + 1) + request revision + audit |
| approve | capability change_review + scope toàn bộ affected entries + không phải proposer + request PENDING + expected_version khớp + từng item expected_version khớp | APPROVED + apply canonical + entry revisions + request revision + audit |
| reject | như approve (trừ bước apply) | REJECTED, canonical **không đổi** + request revision + audit |
| no-op / payload sai | RPC guard | 22023 → 400 |

Pending request **không** đổi canonical; chỉ approve mới apply (DEV acceptance kiểm riêng).

## 3. Boundary authority / OCC / idempotency

| Hạng mục | Nơi quyết định |
| --- | --- |
| Session | `auth.getUser()` qua `getDirectEntryActor` (không dùng getSession) |
| Actor | server-derived `auth_subject` + `app_user_id`; client không gửi |
| Capability change_request_create / change_review | RPC `direct_entry_assert_actor` |
| Scope từng entry | RPC `direct_entry_assert_entry_access` |
| Self-review | RPC `direct_entry_decide_change_request`: proposer = actor ⇒ 42501 |
| OCC | expected_version của request (và của từng item khi approve) ⇒ 40001 |
| Idempotency | `direct_entry_idempotency_*` theo action change_request_create / _withdraw / _approved / _rejected |
| Atomic multi-entry | Một transaction: item đầu đã apply vẫn bị rollback khi item sau stale (DEV acceptance chứng minh) |

Idempotency key nằm trong body; nếu client gửi kèm header `idempotency-key` thì phải khớp body, lệch ⇒ 400 `IDEMPOTENCY_KEY_MISMATCH`. Application không tự retry khi payload đổi (changed payload cùng key ⇒ 409).

Application **không** đọc trước DB để tự đánh giá quyền/trạng thái ⇒ không có TOCTOU và không có authority thứ hai.

## 4. Request projection (fail-closed)

| Envelope | Exact keys |
| --- | --- |
| create | items, reason, idempotency_key |
| withdraw | expected_version, idempotency_key |
| decision | decision (approve | reject), expected_version, reason, idempotency_key |

Từ chối ở mọi độ sâu: trường authority/derived (danh sách lõi **tái sử dụng** `findForbiddenClientField` của S01A, cộng thêm proposer/reviewer/decided_by/decided_at/outcome/result/reused/item_id…). Ngoại lệ duy nhất: `state` là key hợp lệ trong proposal PAYMENT — được miễn đúng tại tầng proposal, và bộ key proposal vẫn bị kiểm exact nên không mở rộng vocabulary.

`items` rỗng, > 100, trùng entry_id, expected_version sai kiểu, reason rỗng/> 4000, idempotency key rỗng/> 128/ký tự điều khiển ⇒ 400 `CHANGE_REQUEST_INVALID`.

| Tình huống | HTTP | Code |
| --- | --- | --- |
| Gate tắt | 404 | NOT_FOUND |
| Sai origin | 403 | CSRF_REJECTED |

| Content-type/body sai | 400 | CONTENT_TYPE_INVALID / BODY_INVALID |
| Request sai | 400 | CHANGE_REQUEST_INVALID |
| Trường authority (kể cả lồng) | 400 | CLIENT_AUTHORITY_FIELD_FORBIDDEN |
| Header/body idempotency lệch | 400 | IDEMPOTENCY_KEY_MISMATCH |
| Chưa đăng nhập | 401 | UNAUTHENTICATED |
| Actor thiếu/malformed/disabled | 403 | ACTOR_NOT_AVAILABLE |
| Capability/scope/self-review/proposer mismatch | 403 | CHANGE_REQUEST_DENIED |
| Không tìm thấy request | 404 | CHANGE_REQUEST_NOT_FOUND |
| Không tìm thấy entry (create) | 404 | ENTRY_NOT_FOUND |

Raw DB message, stack, auth claim, reason và PII không bao giờ ra response/log (có test bắt console.error). Lỗi bất ngờ từ repository cũng được bọc thành 500 sanitized.
