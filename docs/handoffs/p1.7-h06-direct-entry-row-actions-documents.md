## 3. Spreadsheet-style row selection (theo `clientRowId`)

- `DirectEntrySpreadsheetGrid` thêm props `selectedClientRowId?: string | null` + `onSelectedClientRowChange(id: string | null)`.
- Truyền xuống `react-data-grid` qua `selectedRows={selectedClientRowId ? new Set([selectedClientRowId]) : new Set()}` và `onSelectedRowsChange={(set) => onSelectedClientRowChange(set.size > 0 ? Array.from(set)[0] : null)}`.
- Lợi:
  - Khi user click/focus một cell, ngay lập tức xác định `clientRowId` đang chọn (không dùng row index).
  - Selection hoạt động với cả staged row (`spreadsheet-row-N`) và persisted row (`rowId`).
  - Selection không mutate cell data.
  - Sau reload/reorder, `selectedSpreadsheetRow = useMemo(...)` lookup lại theo `clientRowId` — nếu row đó không còn tồn tại (vd đã xóa) thì trả về `null` (stale-safe), không action nhầm NLĐ.

## 5. `Xóa dòng` (exact-row delete)

- Source-of-truth: `clientRowId` do DataGrid selection cung cấp. `onStagedDelete` chỉ gọi `deleteSpreadsheetRow(stagedModel, clientRowId)`; không xóa persisted draft; không gọi API; không tái sử dụng `clientRowId`.
- Disabled khi:
  - Không có selection.
  - Selection là persisted row (H06 không có API xóa persisted data — chỉ staged).
- Sau khi xóa:
  - Clear selection an toàn (`setSelectedClientRowId(null)`).
  - Không tự mở drawer.
  - Duy trì blank/spare-row invariant hiện có (`spreadsheetRowIsBlank`, `selectNonEmptySpreadsheetRows`).
- Regression cover (H06-8):
  - 3 staged rows, chọn row giữa, xóa → chỉ row giữa biến mất, 2 row còn lại giữ nguyên ID + dữ liệu.
  - Chọn persisted row → nút `Xóa dòng` disabled, không xóa gì.
  - Stale selection (selectedClientRowId không tồn tại) → fail-safe, không tác động row khác.

## 6. `Hồ sơ NLĐ` (theo `entry_id`)

- Nguồn mở: `entry_id` của persisted row hiện được chọn — KHÔNG dựa vào row index, họ tên, CCCD hay bất kỳ field PII nào.
- Click mở `DirectEntryWorkerDocuments` dialog (Radix `Dialog`):
  - Họ tên + Mã NLĐ (server cấp) trong tiêu đề; **không** hiển thị toàn bộ số CCCD, storage key, checksum, bucket, signed URL.
  - Section 1: `CCCD_FRONT` (qua `DirectEntryCccdManager`).
  - Section 2: `CCCD_BACK` (qua `DirectEntryCccdManager`).
  - Section 3: `EMPLOYMENT_CONTRACT` (qua `DirectEntryDocumentEditor`).
- Mỗi section có:
  - Native file browser (`<input type="file">`).
  - Trạng thái: `chưa tải` / `đang tải` / `hoàn tất` / `lỗi` (không optimistic READY).
  - Retry / thay thế file đúng flow hiện có.
- Reuse **đầy đủ**:
  - `DirectEntryCccdManager` (CCCD slots).
  - `DirectEntryDocumentEditor` (`EMPLOYMENT_CONTRACT` + các document type khác).
  - reserve → signed PUT → finalize (transport hiện có, không tạo mới).
  - Document detail projection/cache hiện có.
  - OCC, idempotency, partial-failure semantics.
  - Capability `document_view` / `document_upload` / `entry_own` (từ actor session).

## 7. Sau khi lưu NLĐ mới

- Sau quick save hoặc batch save thành công, `reloadDrafts` được gọi; entry_id trả về từ server được lưu vào `selectionAfterSaveEntryId`.
- Trong render, resolve `entry_id` → `rowId` qua `rows.find((row) => row.entryId === target)`:
  - Nếu tìm thấy → set `selectedClientRowId` + `savedCtaClientRowId` tới persisted row đó; clear signal.
  - Nếu `rows.length > 0` mà không match (server cấp entry_id không tồn tại) → clear selection an toàn, không đoán theo tên/CCCD/row index.
- CTA hiển thị: `Đã lưu — chọn Hồ sơ NLĐ để tải tài liệu` (khi `savedCtaClientRowId === selected.clientRowId`).
- Không tự mở file browser, không tự upload, không optimistic projection.
- Resolution ở render body (không dùng `useEffect` + `setState`) để tránh `react-hooks/set-state-in-effect` cascade render.
