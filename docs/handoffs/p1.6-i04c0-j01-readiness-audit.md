## 6. Đề xuất activation order

Dựa trên source + handoff + matrix, thứ tự kích hoạt production an toàn:

1. **Phase A (default Production hiện tại)** — không cần thay đổi. Đã verify
   bởi I04B2 preflight. Có thể chạy smoke bất kỳ lúc nào.
2. **Phase B (API on, UI off)** — set `DIRECT_ENTRY_API_ENABLED="true"`. Smoke
   15 route API qua Basic Auth + Supabase session (OWNER + REVIEWER + UNAUTH).
   Verify OCC, idempotency, capability, redaction. R2 vẫn unset ⇒ smoke
   `documents/reserve` phải trả 503 `DOCUMENT_STORAGE_UNAVAILABLE`.
3. **Phase B-2 (R2 wire-in)** — set `R2_ACCOUNT_ID`, `R2_BUCKET_NAME="hrp-bi-product"`,
   `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`. Verify `loadR2Config` trả object
   hợp lệ qua PGlite test hoặc staging dry-run; smoke `documents/reserve` ⇒
   201 với `upload.url` (TTL 300s). Verify Object trong bucket có đúng prefix
   `production/staging/...`. Sau khi finalize, object trong `production/final/...`
   + staging xoá.
4. **Phase C (UI on)** — set `DIRECT_ENTRY_UI_ENABLED="true"`. Browser acceptance
   trên Production domain với OWNER session thật. Sau khi pass, **chưa**
   tuyên bố I04 PASS / P1.6 PASS — chờ acceptance rộng hơn.
5. **Phase C-2 (Drain)** — quan sát reporting baseline + audit log 24 giờ. Nếu
   ổn định thì J01 closure evidence có thể ký.

**Rollback**: tại bất kỳ pha nào, set flag về unset/false hoặc xoá `R2_*`
⇒ tự động fail-closed (404 cho API + Navbar ẩn + `/direct-entry` 404).
