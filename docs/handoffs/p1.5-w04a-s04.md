# P1.5-W04A-S04 — Owner-ready AI Settings Panel

## Outcome
Refactor AiSettingsPanel sang Radix Dialog/Sheet + AlertDialog + Select, luồng Owner-ready Save -> Test -> Activate, API key không lộ/persist client. Chưa nhập secret thật, chưa gọi provider thật.

## A. Overlay refactor
- Dialog.Root/Trigger/Portal/Overlay/Content/Title/Description/Close — Radix quản lý focus trap, Escape, focus return, overlay click.
- AlertDialog cho confirm-discard VÀ confirm-disable (thay window.confirm).
- Không còn focus trap thủ công (xóa FOCUSABLE_SELECTOR, addEventListener keydown/focusin, inert). resolveTabTarget/confirmInitialFocusIndex giữ trong logic file vì ai-report-panel vẫn dùng.
- Desktop side panel sm:w-[30rem], mobile full-height, nội dung overflow-y-auto.

## B. Form fields (4 field)
- Provider profile: Radix Select (profile từ server provider_profiles), mô tả "OpenAI-compatible".
- API URL: placeholder ví dụ, hint "Bắt buộc HTTPS", sau lưu chỉ hiện sanitized_host (không full URL).
- Model: input text (trim/NFC theo server contract).
- API key: type=password mặc định + Eye/EyeOff (lucide), autoComplete="new-password", spellCheck={false}, data-1p-ignore, không prefill/không hiện key đã lưu/không persist, clear sau save/rotate/discard/close.

## C. Guided flow (3 bước)
- flowStepOf(status) (logic thuần): chưa lưu -> bước 1; draft/test_failed/rotation_required -> bước 2; verified -> bước 3; active -> xong; disabled -> 0.
- Enable rules: Save (URL HTTPS + model + key); Test (đã lưu); Activate (verified); Rotate (đã có config + key mới); Disable (active).
- Không tự Test sau Save, không tự Activate sau Test, không gọi provider khi mở panel.
- Hint: "API key được mã hóa phía máy chủ và không hiển thị lại sau khi lưu."

## D. Config summary (sanitized)
- Card "Cấu hình hiện tại": profile, sanitized_host, model, version, status, verified_at, updated_at, key_fingerprint (rút gọn 8 ký tự).
- Badge semantic (success/warning/muted/error). Không hiển thị API key/ciphertext/full URL/raw response/DB error.

## E. Advanced actions
- Xoay API key trong disclosure; yêu cầu verify lại sau rotate.
- Tắt cấu hình dùng Radix AlertDialog ("Báo cáo AI sẽ fail-closed", giữ lịch sử/revision).

## F/G. Error/Loading/OCC + responsive/a11y
- Skeleton loading, Alert (role=alert) cho lỗi, aria-live=polite cho status, aria-invalid + aria-describedby cho field.
- OCC: expected_version, AI_VERSION_CONFLICT/409 -> reload projection, giữ thông báo, không tự retry.
- Touch target min-h-11 (>=44px), label thật, icon-only có aria-label, Radix focus/focus-return, không màu là tín hiệu duy nhất (Badge có text).
