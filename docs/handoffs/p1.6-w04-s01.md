## Recruiter/team/bank typeahead

The minimal unmounted picker smoke is
`src/components/direct-entry/typeahead-picker-smoke.tsx`; all visible fixture
labels and IDs are synthetic. It receives an already-active/effective
projection, displays recruiter provider/team and entity group labels, and
emits only a selected stable ID. It has no actor-to-recruiter mapping input
and starts with no selection. Server-side projection and authorization remain
the production trust boundary; the component does not establish them.

The pure helper `src/lib/direct-entry/typeahead.ts` normalizes query and
labels to NFC, compares case-insensitively using Vietnamese locale rules, and
returns matching IDs only. The focused tests cover `C` / `Co`, CongHr1/2 and
Chung suggestions, case-insensitive matching, composed/decomposed Vietnamese
text, stable-ID results, wrapped arrow movement, Enter, Escape, Tab, and the
IME-composition guard. The picker closes on Tab without preventing normal
focus movement; Enter commits only an explicitly active option.

### Decision matrix

| Requirement | Native input + listbox | `cmdk@1.1.1` |
|---|---|---|
| Query normalization and deterministic filtering | PASS; helper tests | Not needed to implement |
| Stable ID as selected value | PASS; only ID is emitted | Would still need the stable-ID adapter |
| Provider/team/group labels | PASS; rendered from option metadata | Would still need domain labels |
| Arrow, Enter, Escape, Tab behavior | PASS; explicit key policy used by picker | No required behavior gap identified |
| IME does not commit while composing | PASS; component checks native composition state and helper tests the guard | No tested advantage over native |
| Incremental runtime dependency | None | Adds `cmdk` |

**Decision: GO with native input/listbox; NO-ADD `cmdk`.** The native
implementation meets the focused contract with no dependency and less
adapter code. `cmdk` is not installed. Revisit only if S02's integrated UX
shows a concrete keyboard, filtering, or accessibility gap.
