## Integration API

`direct-entry-grid-columns.ts` exports:

- `DIRECT_ENTRY_GRID_COLUMNS`: immutable 27-column physical paste order.
- `directEntryGridColumn(key)` and `directEntryGridColumnIndex(key)`.
- Column/editor/paste-mode types. The first 24 columns retain their exact
  `WORKER_PROFILE_FIELDS` object as `contractField`; the last three are UI-only columns.

`direct-entry-grid-clipboard.ts` exports:

- `parseClipboardTsv(text)`: CRLF/LF TSV parser preserving Unicode, leading zeroes and empty cells.
- `serializeClipboardTsv(matrix)`: rectangular TSV serializer.
- `mapClipboardFromAnchor(...)`: atomic bounds check and coordinate mapping with separate
  `writeCells`, `validationCells` and `ignoredCells`.
- `captureClipboardUndoSnapshot(...)` and `restoreClipboardUndoSnapshot(...)`: one-level paste undo;
  W01B supplies its own pure row reader/writer, so W01A does not define a competing row model.
- `DIRECT_ENTRY_GRID_MAX_ROWS`: reused from the existing `PASTE_MAX_ROWS` contract (100).
